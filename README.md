# iac-aws

Terraform IaC for personal AWS instructure managed byGitOps.

## Overview
- AWS resources managed by Terraform with s3 + DynamoDB backend
- Github Actions OIDC authentication (no long-lived AWS Keys)
- Teraform outputs automatically synced to GitOps repo via cross-repo PR
- Companion repo: [`homelab`](https://github.com/Kagayama0208/homelab) (keiba-db)
